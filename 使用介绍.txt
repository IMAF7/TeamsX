================================================================================
  TeamsX 多账号 Teams 管理器 — 详细使用与功能说明
  版本：2.2.0  |  适用：Windows 10/11 64 位
================================================================================

一、软件是什么
--------------------------------------------------------------------------------
TeamsX 是一款在 Windows 上运行的 **Microsoft Teams 网页版多账号管理工具**。

主要能力：
  · 在一个窗口里管理多个 Teams 账号（独立登录态，互不串号）
  · 左侧账号列表 + 右侧 Teams 网页（默认 Edge WebView2 内核）
  · 内置 TeamsXAi（DeepSeek 对话，与 Teams 隔离，按 Esc 回到 AI 主界面）
  · 未读角标、网页内提示音/提醒、分组、置顶、锁定、缓存清理等

数据默认保存在：D:\TeamsX（可用环境变量 TEAMSX_DATA_ROOT 修改）


二、系统与运行环境
--------------------------------------------------------------------------------
【必需】
  · Windows 10 / 11，64 位系统
  · Python 3.10+ 64 位（源码运行）或官方打包的 exe
  · Microsoft Edge WebView2 Runtime 64 位（多数电脑已随 Edge 安装）
  · 建议 D 盘可用（默认数据目录 D:\TeamsX）

【Python 依赖（开发/源码运行）】
  pip install PyQt6 qtwebview2 qtpy pythonnet pywin32 certifi
  pip install markdown mistune pygments chardet   # AI 与导入辅助
  （已移除 QtWebEngine 依赖，项目为 WebView2-only）

【启动方式】
  方式 1（推荐）：
    cd 到程序目录
    python -m teamsx

  方式 2：
    python TeamsX.py

  正常启动日志示例：
    [TeamsX] Teams 页面引擎: WebView2
    [TeamsX] 当前 Teams 引擎: webview2
    TeamsX 启动完成 · 数据: D:\TeamsX · 并发上限: 5

【可选环境变量】
  TEAMSX_DATA_ROOT          数据根目录，默认 D:\TeamsX
  TEAMSX_WEBVIEW2_BROWSER_FOLDER   固定版 WebView2 x64 运行时目录
  （不再支持 TEAMSX_ENGINE=qtwebengine 回退/强制 Qt 内核）

更多技术说明见同目录 ENV.md、BUILD.md。

【圆点状态】
  绿色 — 已验证登录且当前在活跃池（正在或刚用过）
  黄色 — 已验证登录但处于休眠（登录态保留，不占活跃槽位）
  红色 — 未登录 / 登录失败 / 尚未验证

【红色数字角标】
  账号右侧红色数字为 Teams 未读消息数（来自网页标题/DOM 同步）。


四、账号管理
--------------------------------------------------------------------------------
4.1 添加单个账号
  · 点侧栏「添加」
  · 填写备注（必填）、邮箱 Z、密码 M/N（可选，用于自动填表登录）
  · 添加后 **点击列表中该账号** 才会打开 Teams 并登录

4.2 B/Z/M 批量导入
  · 点「导入」，选择 txt 文件（单文件最大约 10MB）
  · 格式（空行分隔多条，也支持 accounts.txt 同步）：

      B:备注名称
      Z:邮箱@example.com
      M:密码

    或中文键名：备注 / 账号 / 密码

  · 导入后不会自动全部登录，需 **逐个点账号** 登录（一次登录一个）

4.3 点击账号 / 切换账号
  · 单击列表项 → 右侧打开该账号 Teams
  · 若 DB 中有邮箱密码且未登录成功 → 自动填 Microsoft 登录页
  · 同时最多 **5 个活跃** Teams 页面；第 6 个上线时，**最不活跃** 的会被 **休眠**
  · 休眠账号最多保留 **50 个**；超过时 **最久未用的休眠页会被断开**（登录数据仍在磁盘，再点会重新加载）

4.4 右键菜单（在账号上右键）
  · 编辑备注 — 仅改显示名，**不会**改变 profile 目录、不会丢登录态
  · 置顶 / 取消置顶 — 置顶账号最多 20 个，排在列表前部
  · 分配到分组 / 修改分组
  · 删除账号 — 会卸载 WebView 并删除该账号数据目录

4.5 分组
  · 侧栏「分组」下拉筛选
  · 「管理」→ 新建/编辑/删除分组，勾选成员

4.6 搜索
  · 侧栏搜索框按 **备注** 模糊过滤


五、Teams 页面与登录
--------------------------------------------------------------------------------
5.1 引擎
  · 默认 **WebView2**（与系统 Edge 同源，视频/会议/DRM 支持最好）
  · 行为原则：不拦截 window.open / SharePoint / 新窗口，与 Edge 开 Teams 一致

5.2 登录
  · 一次只主动登录一个账号（点谁登谁）
  · 登录过程会尽量屏蔽通行密钥弹窗、优先密码登录
  · 登录超时约 300 秒
  · 登录成功后圆点变绿；失败变红，可再次点击重试

5.3 Esc 键
  · 在 Teams 界面按 **Esc** → 回到 **TeamsXAi** 主界面（不清登录态）
  · 若误触视频全屏导致整窗全屏，Esc 也可退出全屏

5.4 刷新
  · 侧栏「刷新」：当前 Teams 白屏/异常时尝试 **全局修复**（重建引擎并恢复当前账号）

5.5 通知
  · 侧栏「通知:开/关」控制 Teams **网页内** 提示音与页面内提醒
  · **不是** Windows 系统托盘通知
  · 关闭通知时仍同步未读 **角标数字**

5.6 关于别人发的视频 / SharePoint「需要访问权限」
  · 这是 Teams 网页 + 跨用户 SharePoint 的 **Microsoft 侧限制**，不是 TeamsX 独有 bug
  · 若把链接复制到 Edge 浏览器也要登录/没权限，需在 Teams 里向发件人申请共享
  · TeamsX 不会也不应强行破解此类链接


六、TeamsXAi（内置 AI）
--------------------------------------------------------------------------------
6.1 进入方式
  · 启动后右侧默认即为 TeamsXAi
  · 从 Teams 返回：按 **Esc**（无侧栏 AI 按钮， intentionally 简化）

6.2 API Key
  · 使用 DeepSeek API
  · Key 保存在：D:\TeamsX\ai_deepseek.json
  · 首次发消息时若未配置会提示输入
  · 换电脑可复制该文件，或重新填写

6.3 使用
  · 底部输入框输入，Enter 发送，Shift+Enter 换行
  · 流式输出，支持 Markdown / 代码高亮
  · 与 Teams 账号、WebView **完全隔离**，不涉及 Teams 登录态


七、锁定功能
--------------------------------------------------------------------------------
7.1 首次使用
  · 点侧栏「锁定」→ 设置锁定密码（需确认两次）

7.2 锁定后
  · **标题栏始终可见**（最小化/最大化/关闭仍可用）
  · 下方内容区隐藏，仅显示 **密码输入框**
  · 输入正确密码按 Enter 解锁
  · 锁定期间无法点击账号列表切换

7.3 说明
  · 锁定是 **界面隐私锁**，不是 Windows 系统级加密
  · 密码保存在本地数据库 settings 表（PBKDF2 哈希）


八、缓存清理
--------------------------------------------------------------------------------
8.1 手动清理
  · 点侧栏「清理」
  · 后台清理 **全部账号** 的浏览器磁盘缓存（Cache、Code Cache、GPUCache 等）
  · **保留** Cookies / Local Storage / IndexedDB → **一般无需重新登录**
  · 完成后弹窗显示 **释放空间大小**（若正在使用的页面会先走 WebView2 内存清缓存，避免文件锁）
  · 状态栏也会显示「已释放约 xxx」

8.2 自动清理
  · 每天 **7:00 之后** 自动清理 **一次**（软件运行中到点触发；7 点后打开软件也会补跑）
  · **无弹窗**，不影响正常使用
  · 当天已清理过则不再重复

8.3 数据目录说明
  · profiles\account_<ID>\session  — WebView2 用户数据（含登录）
  · cache\account_<ID>            — 独立 cache 目录（Qt 回退时用）
  · 删除整个 D:\TeamsX 文件夹 = 清空全部账号与 AI Key


九、WebView 池与内存策略（当前配置）
--------------------------------------------------------------------------------
  · 活跃上限：5（同时在线 Teams 页）
  · 休眠上限：50（保留登录态，隐藏页面）
  · 超出活跃 → 休眠最不活跃
  · 超出休眠 → 断开最久未用的休眠 WebView（session 仍在，再开需 reload）
  · 内存维护定时器：仅在活跃槽满时参与休眠决策
  · 不再定时清 HTTP 缓存（避免多账号集体白屏）

十一、数据文件结构（D:\TeamsX）
--------------------------------------------------------------------------------
  D:\TeamsX\
    db\teams_accounts.db     账号、分组、设置（含锁定密码哈希）

十三、常见问题
--------------------------------------------------------------------------------
Q: 启动报 WebView2 相关错误？
A: 安装/修复 Edge WebView2 Runtime 64 位；或设置 TEAMSX_WEBVIEW2_BROWSER_FOLDER
   指向固定版 x64 运行时目录。需 64 位 Python。

Q: 白屏？
A: 点「刷新」等待全局修复；仍不行重启软件。

Q: 登录检测 not_teams？
A: 网络/代理/账号未完成登录；多试或检查 Microsoft 登录页。

Q: AI 报 SSL 证书错误？
A: 确保 certifi 已安装；打包版需用最新 build。

Q: 改备注后登录丢了？
A: v2.2.0 起 profile 目录固定为 account_<ID>，改备注不影响路径。
   旧版若已有旧目录名数据，仍使用 DB 里记录的原路径，无需迁移。

Q: 清理后还要重新登录？
A: 正常不应。若发生，可能是该账号 session 损坏，删除账号重新添加。

Q: 如何彻底卸载数据？
A: 关闭 TeamsX，删除 D:\TeamsX 整个文件夹。


十四、版本 2.2.0 相对旧版的主要改进（摘要）
--------------------------------------------------------------------------------
  · 单内核 WebView2 为默认，行为对齐 Edge Teams
  · 启动入口统一到 teamsx 包；bootstrap / 引擎拆分
  · 锁定遮罩不挡标题栏；锁定界面仅密码框
  · 缓存：WebView2 磁盘清理、每日 7 点自动清理、手动显示释放量
  · 活跃 5 / 休眠 50 策略
  · 修复：改备注不重建 profile、登录失败不删正在用的缓存、列表排序按 DB、
          桥接回调主线程、清理时跳过正在使用的 profile 等
